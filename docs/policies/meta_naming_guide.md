# 🎯 Meta広告入稿ガイドライン（2025年8月16日策定）

## 📋 基本ルール

**Meta広告名の命名規則:**
```
広告グループ_クリエイティブNo
例：25_CR-46, 22_CR-n03, 26-001_CR-50_014-01
```

**リンク先URLのutm_creativeパラメータ:**
```
utm_creative=広告グループ_クリエイティブNo
例：utm_creative=25_cr-46, utm_creative=22_cr-n03
```

**重要な原則:**
- `_`の前 = **広告グループ**（数字、ハイフン含む可）
- `_`の後 = **クリエイティブNo**（CR-形式、アンダースコア含む可）
- **案件名 + 広告グループ_クリエイティブNo** で一意性を保つ

## 🏢 案件別設定

| 案件名 | Meta広告アカウント | 自動検出方式 |
|--------|-------------------|-------------|
| 案件B | 353999830205773（カンシャ） | BigQueryから自動検出 |
| ロコヘルプ_FB | 7338608252880897（ロコヘルプEX） | BigQueryから自動検出 |

**重要**: クリエイティブパターンは固定ではありません。同じパラメータ（例：`01_cr-09`）が複数案件で使用される可能性があるため、**案件名 + パラメータ名** の組み合わせで一意管理します。

## ✅ 入稿時チェックリスト

**1. 広告名確認**
- [ ] `広告グループ_クリエイティブNo` 形式になっている
- [ ] アンダースコアが正しく使用されている
- [ ] BigQueryの自動検出により案件に対応している

**2. URLパラメータ確認**
- [ ] `utm_creative=` パラメータが設定されている
- [ ] utm_creativeの値が広告名と完全一致している
- [ ] 大文字小文字が正確（通常は小文字で統一）

**3. アカウント確認**
- [ ] 正しい案件のMeta広告アカウントで入稿している
- [ ] 案件名が正しく設定されている（自動検出対象）

## 🚨 よくある入稿ミス

**❌ 間違った例:**
```
広告名: 25CR46（アンダースコア抜け）
URL: utm_creative=25_cr-46（広告名と不一致）
```

**✅ 正しい例:**
```
広告名: 25_CR-46
URL: utm_creative=25_cr-46
```

## 🔧 トラブルシューティング

**データが統合されない場合:**
1. 広告名とutm_creativeパラメータの一致確認
2. 案件名の正確性確認
3. BigQuery統合ビューでのデータ確認

**確認コマンド:**
```sql
SELECT report_name, utm_creative_raw, COUNT(*) 
FROM meta_ads_hourly_with_report 
WHERE date_str = CURRENT_DATE()
GROUP BY report_name, utm_creative_raw
```

## 📞 緊急時対応

**データ不整合を発見した場合:**
1. 即座にCLAUDE.mdの「緊急修正必要事項」セクションに記録
2. BigQueryでのデータ修正（逆転修正等）
3. ソースコードの修正（extract_meta_data.py、meta_api_handler.py）
4. 統合ビューの再作成

**このガイドラインにより、Meta広告とSquadBeyondデータの正確な統合を実現する。**
